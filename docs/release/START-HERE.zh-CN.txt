Hagane Works Windows 便携版

1. 把整个 ZIP 解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 HaganeWorks.exe。
3. 第一次启动时选择创作目录，并确认《钢铁雄心 IV》的安装目录。
4. 新建项目或导入现有 Mod，完成后在“导出”页生成 ZIP 或安装到游戏。

本软件不需要安装 Node.js、Go、Python、数据库或服务器。界面和中英文知识库已经嵌入程序。

Windows 10/11 通常自带 Microsoft Edge WebView2。缺少 WebView2 时，程序会改用默认浏览器打开本机界面。

版本选择：
- windows-x64：绝大多数 Intel/AMD 电脑，优先下载这一版。
- windows-x86：仅用于 32 位 Windows。
- windows-arm64：Windows on ARM 设备。

命令行工具：
- hw.exe 可以让本机脚本和其他程序调用编辑器工具。
- 命令、JSON 输入格式和本机接口安全机制见 docs/cli.md。

如果 Windows SmartScreen 提示未知发布者，是因为当前版本尚未使用商业代码签名证书。请只从项目官方发布页下载，并核对 SHA256SUMS.txt。
